# 012 — The murloc icon and the first portable zip release

## Context

An icon of our own drawing, a murloc face as fan art within D-005 (no game file, no Blizzard logo),
replacing the placeholder glyph in `crates/mrgl-app/icons/` and the title bar; then the first `v0.1.0`
release through `scripts/release.ps1` and the tag workflow. The themes are in the design sketch (017). The
zip carries `lists/forever-starter.json` (028) so its one import command works without the repo, and the
release closes its milestone by step 4 of the release list (033). A face for the name, and a release is how
anyone else runs it.
Done when: the icon shows in both exes, the window and the taskbar, and the release page carries the zip, the
checksum and the attestation.

Decided 2026-10-22: starts from the tip of task 010's branch, so the first release carries the window's
update. The task session prepares everything up to and including step 1 of the release list (the icon, the
list in the zip, the version bump to 0.1.0, the *Unreleased* summary in `CHANGELOG.md`); the tag, the release
page and the milestone close are the maintainer's steps after the merge, and the done-when is checked then.

## Log

- 2026-10-22 — promoted; runs as a task session in its own worktree (docs/maintainer-sessions.md), cut
  from the tip of task 010's branch
- 2026-10-22 — the icon: `scripts/make-icon.py` draws a flat murloc head from geometry on a 256-unit square
  (a round head, two big round eyes set high with pupils looking up and inward, a wide grin with four teeth,
  a three-spike crest and a two-point ear fin on each side, a dark outline), in the theme tokens of
  `style.css`: the dark theme's accent for the skin, the light theme's accent for the fins, the dark
  warning amber for the crest, the light background for the eyes and the teeth, the dark accent foreground
  for the outline and the mouth. Each of the ten `.ico` sizes (16, 20, 24, 32, 40, 48, 64, 96, 128, 256 px)
  is drawn on its own at four times its size and scaled down; below 32 px the outline is one output pixel,
  the eyes lose their outline and highlight and move apart, and the teeth and the belly are left out, so
  the face reads at 16 px. `icon.png` is the same drawing at 512 px. A rerun writes the same bytes.
- 2026-10-22 — two drawing fixes after the first render: Pillow's polygon outline grows inward and ate the
  thin crest spikes and the teeth, so polygon outlines are now lines centred on the edge and the teeth have
  none; at 16 to 24 px the two eyes merged into one white band, fixed by the smaller, wider-set eyes of the
  small sizes.
- 2026-10-22 — the CLI's icon without a new crate: `crates/mrgl-cli/build.rs` (standard library only)
  rewrites `crates/mrgl-app/icons/icon.ico` as a compiled resource file (`.res`: the empty leading entry,
  one `RT_ICON` per image, the `RT_GROUP_ICON` 1 that lists them, the layout `rc.exe` writes) into
  `OUT_DIR` and passes it with `cargo::rustc-link-arg-bins` to the MSVC linker, which takes a `.res` as an
  input file; other targets skip it. `Cargo.toml` and `Cargo.lock` are unchanged.
- 2026-10-22 — `tauri-build` asks to rerun only on `tauri.conf.json` and the capabilities, so the first
  rebuild kept the old glyph in `mrgl-app.exe`; `crates/mrgl-app/build.rs` now declares
  `rerun-if-changed` on `icons/icon.ico` and `icons/icon.png`, and touching the `.ico` rebuilds the app.
- 2026-10-22 — `scripts/release.ps1` copies `lists\forever-starter.json` into the zip at its repo path
  (checked to exist before packing, with the exes); `scripts/changelog.py`'s release notes footer names the
  list and its import line.
- 2026-10-22 — docs: `docs/development.md` (the CLI crate's `build.rs` in the layout; the icon paragraph of
  "The UI": the drawing, the sizes, the colors, both build scripts and the regeneration command; "The
  release": the list in the zip), `README.md` (an "Install" section: the zip, the checksum, the attestation
  check, the unpacked folder's content and the starter list's import; the starter-list bullet; the project
  status), `CHANGELOG.md` (the *Unreleased* summary for 0.1.0, regenerated).

## Deviations from the plan

- The icon needed no light-theme variant: one drawing with a dark outline and the bright skin reads on the
  light and the dark title bar and taskbar.
- Beyond the plan: `crates/mrgl-app/build.rs` reruns on the icon files (without it a regenerated icon never
  reached `mrgl-app.exe` before a clean build), and the release notes footer in `scripts/changelog.py`
  names the starter list.
- The README's project status and install section describe the 0.1.0 release, which exists once the
  maintainer pushes the tag after the merge.
- The done-when's release page (the zip, the checksum and the attestation on GitHub) is checked after the
  merge with the tag, by the decision of 2026-10-22 above; this change verified everything up to it.
