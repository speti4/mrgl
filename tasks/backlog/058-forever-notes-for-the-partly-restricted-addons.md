# Forever notes for the addons the community lists as partly restricted

What: the research page gains the addons a community source names as partly restricted on Forever (the
aura and nameplate addons that read combat values), each with the source and the date, and the curated
notes file (011) gains one entry per addon with its kind.
Why: the curated file starts with the restriction kinds and no addon; the first users will ask about
exactly these addons.
Done when: the research page lists them with sources, the data file carries them, and `list` on a
Forever folder with one of them installed shows the note.
