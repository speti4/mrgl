# Forever notes dataset: dead, crippled or viable, from the research

What: a small data file (addon name → Forever status and a one-line reason) built from the community
compatibility lists, shown as a note on an addon's row in the window and in `mrgl list`.
Why: Forever hides combat values and removes the combat log; a user should see why an addon will not work
before installing it.
Done when: the addons of the research page carry a note, and the dataset has a `Verified:` date and sources.
