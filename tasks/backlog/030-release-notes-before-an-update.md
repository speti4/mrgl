# Release notes before an update: the GitHub release body in one line

What: the first line of the GitHub release body in `update --dry-run` and in the window's row (010), with
the release page's link; the body comes with the release list the source (003) already fetches.
Why: knowing what an update changes before taking it, and a link to the rest when one line is not enough.
Done when: a fixture release with a body shows its first line and the link, and an empty body shows nothing.
