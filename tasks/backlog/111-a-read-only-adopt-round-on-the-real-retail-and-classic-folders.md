# A read-only adopt round on the real retail and classic folders

What: `mrgl adopt --flavor` run once, read-only, on the maintainer's real retail, classic and era folders
(managed by the CurseForge app today), the summary counts recorded in the task file without any addon or
folder name: how many addons adopt without CurseForge, how many only with it, how many have no known
source, and how many of the hinted sources answer "needs <KEY NAME>".
Why: the counts measure the roadmap's M4 goal (most addons of the retail and classic folders recognized)
and decide whether fingerprint matching is worth a task of its own; no write and no key is needed.
Done when: the three counts per folder are in the task file's Verification and a decision line says whether
fingerprint matching is filed or dropped.
